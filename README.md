# AI Mood Analyzer 🤖

Небольшой учебный AI-проект на Python, который определяет настроение короткого текста:
- positive — положительное
- negative — отрицательное
- neutral — нейтральное

## Как запустить

1. Установите Python 3.
2. Установите зависимости:
```bash
pip install scikit-learn
```
3. Запустите:
```bash
python mood_analyzer.py
```

Введите текст, и модель покажет предсказанное настроение.

## Что используется

- Python
- scikit-learn
- TF-IDF
- Logistic Regression

Проект создан как небольшой демонстрационный AI/ML проект для портфолио.
